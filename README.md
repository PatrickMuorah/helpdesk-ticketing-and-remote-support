# Helpdesk Ticketing & Remote Support Lab

## Project Overview
A hands-on simulation of Tier 1 IT support workflows using osTicket, 
remote desktop tools, and industry-standard documentation practices.

## Tools Used
- osTicket 
- XAMPP 
- AnyDesk
- Windows 11 VM

## What This Demonstrates
- Ticket lifecycle management (triage → response → resolution → closure)
- Priority assignment with SLA justification
- Customer-facing written communication
- Knowledge base authoring
- Standard Operating Procedure (SOP) design
- Remote troubleshooting and session documentation
